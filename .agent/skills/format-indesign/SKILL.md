# InDesign 태그 포매팅 스킬

번역 파이프라인(`translate-chunk`)이 산출한 JSON 파일을 인디자인에 바로 입고할 수 있는 태그 텍스트로 변환합니다.

## 🚀 발동 조건
- 사용자가 "인디자인용으로 변환해줘", "조판용 태그 적용해줘" 등의 요청을 했을 때
- 번역 JSON 파일이 이미 존재할 때 (예: `pages_1-10.json`)

## 📋 프로세스

### 1단계: 태그 변환 실행
```bash
python src/format_indesign.py \
  --input "translated/antigravity/{폴더}/pages_{START}-{END}.json" \
  --output "translated/antigravity/{폴더}/indesign_ready_pages_{START}-{END}.txt"
```

### 2단계: 결과 확인
- 출력된 `.txt` 파일을 열어 태그가 올바르게 적용되었는지 확인합니다.
- 소제목/장 제목 등이 자동 분류되지 못한 경우 수동 보정합니다.

### 3단계: 완료 보고
- "InDesign 태그 적용 완료. `{출력파일}`을 확인해주세요." 라고 사용자에게 알립니다.

## 📐 태그 규칙

| 태그 | 용도 | 예시 |
|------|------|------|
| `@부 명칭@` | 편(부) 구분 | `@제1부 후아후아의 세계@` |
| `#장 제목#` | 장 시작 | `#제1장 밝고 즐거운 후아후아의 영혼의 소리#` |
| `$"인용구" - 저자$` | 에피그래프 | `$「후아후아, 후아후아」 - 사이토 히토리$` |
| `##소제목` | 1차 중간 제목 | `##깃털보다 가벼운 것이 후아후아` |
| `###세부제목` | 2차 세부 제목 | `###작은따옴표 강조의 비밀` |
| `• 항목` | 불릿 리스트 | `• 천국의 언어 8가지` |
| (태그 없음) | 본문 | 줄바꿈으로만 구분 |

## ⚠️ 주의사항
- 자동 분류가 100% 정확하지 않을 수 있습니다. 특히 짧은 문장이 소제목으로 오분류될 수 있습니다.
- 최종 산출물은 반드시 사용자에게 확인을 요청하세요.
