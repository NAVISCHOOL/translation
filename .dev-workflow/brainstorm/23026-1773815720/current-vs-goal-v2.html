어떤 수준의 서식 재현을 원하시나요?

A

역할 기반 자동 서식 (추천)

번역 MD에서 제목/머리말/본문/인용문/주석/페이지번호 등 역할을 자동 감지하여 크기·색상·여백을 다르게 적용. 번역 MD에 마크다운 문법(##, >, 등)을 활용하거나 패턴 매칭으로 자동 판별.

B

원본 PDF 서식 추출 + 매핑

PyMuPDF로 원본 PDF에서 폰트 크기·위치를 추출하고, 번역 텍스트에 대응시켜 서식 복제. 단, 이 PDF는 OCR 레이어라 폰트 정보가 부정확할 수 있음.

C

번역 시 서식 태그 포함

번역 단계에서 AI가 텍스트 역할을 판단하여 [title], [quote], [note] 같은 태그를 MD에 삽입. 대조 PDF 생성 시 태그에 따라 스타일 적용.
