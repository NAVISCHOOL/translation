어떤 수준의 서식 재현을 원하시나요?

A

역할 기반 서식

제목/본문/인용/캡션 등 텍스트 역할을 구분해서 크기·색상을 다르게 적용. 번역 MD에 마크다운 문법(##, >, 등)으로 역할 표시.

B

원본 서식 추출 + 복제

원본 PDF에서 실제 폰트 크기·색상·위치를 추출(PyMuPDF)하여, 번역 텍스트에 동일한 서식을 자동 적용. 가장 정확하지만 구현 복잡.

C

수동 마크업 + 스타일 시트

번역자가 MD에서 [title], [caption] 같은 태그로 역할을 지정하면, 미리 정의된 스타일 시트로 렌더링. 정확도 높지만 수동 작업 필요.
