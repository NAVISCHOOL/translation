설계안: 대조 PDF 서식 재현

AI 시각 분석 → 인라인 스타일 기록 → 대조 PDF 반영

전체 흐름

Step 1. prepare_pages.py → PNG 이미지 추출 (변경 없음)

Step 2. AI가 이미지 보고 번역 + style: 줄 추가

Step 3. MD 저장 (기존 형식 + style 줄)

Step 4. translate_pipeline.py → MD 파싱 시 style 파싱 추가

Step 5. generate_comparison_pdf.py → 서식 적용 렌더링

style 속성 정의

size small / medium / large / xlarge → 8pt / 10pt / 14pt / 20pt
color black / green / gray / white → #222 / #2e7d32 / #888 / #fff
bold (플래그) → 굵은 폰트 사용
position header / footer / center → 배치 위치
spacing after:small / after:medium / after:large → 아래 여백

수정이 필요한 파일

1. agents/workflows/translate.md — 번역 시 style 줄 기록 규칙 추가

2. .agent/skills/translate-chunk/SKILL.md — 번역 스킬에 style 기록 지침 추가

3. src/translate_pipeline.py — MD 파서에서 style 줄 파싱, JSON에 style 필드 포함

4. src/generate_comparison_pdf.py — style 정보에 따라 폰트 크기/색상/굵기/여백 적용
