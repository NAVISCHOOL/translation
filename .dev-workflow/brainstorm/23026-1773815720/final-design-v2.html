ANTI-STYLE 검증: 픽셀 분석 방식

원리:

1. OCR 레이어에서 각 텍스트 블록의 좌표(위치)를 가져옴

2. 원본 PDF를 고해상도 이미지로 렌더링 (PyMuPDF)

3. 텍스트 좌표 주변의 픽셀 RGB 값을 샘플링 (Pillow)

4. AI가 기록한 color와 실제 픽셀 색상을 비교

5. 불일치 시 픽셀 분석 결과로 자동 교정

 

장점:

• 외부 API 불필요 (Gemini 등 안 써도 됨)

• AI 판단보다 100% 정확

• 이미 있는 PyMuPDF + Pillow로 구현 가능

 

출력 예시:

ANTI-STYLE 검증 (p.8):
  "머리말" (header)    → color=black  ✅ 픽셀 확인: RGB(42,42,42) = black
  "머리말" (title)     → color=green  ✅ 픽셀 확인: RGB(46,85,54) = green
  "시바무라 에미코"    → color=green  ❌ 픽셀 확인: RGB(56,56,56) = black → 자동 교정
  "여러분, 감사합니다" → color=black  ✅ 픽셀 확인: RGB(40,40,40) = black
  → 1건 자동 교정 완료
