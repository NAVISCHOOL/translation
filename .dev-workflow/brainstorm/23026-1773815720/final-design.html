3. 파이프라인 흐름 (변경 후)

기존 MD 파싱 → JSON 저장

기존 ANTI-JAPANESE 검증 (일본어 잔존, 페이지 누락 등)

기존 대조 PDF 생성

신규 MD 파싱 시 style 줄도 함께 파싱 → JSON에 style 필드 포함

신규 대조 PDF 생성 시 style에 따라 폰트 크기/색상/굵기/여백 적용

신규 서식 검증: 생성된 대조 PDF ↔ 원본 이미지 비교, 불일치 리포트

기존 세션 로그 업데이트

4. 서식 검증 시스템 (ANTI-STYLE)

검증 방식:

1. 대조 PDF 생성 완료 후

2. 각 페이지의 원본 이미지 + 기록된 style 정보를 AI에게 전달

3. AI가 원본 이미지를 다시 보고, 기록된 style과 비교

4. 불일치 항목 리포트 출력

 

출력 예시:

✅ STYLE 검증 결과 (p.8)
  블록 1 "머리말" (header): OK
  블록 2 "머리말" (title): OK
  블록 3 "시바무라 에미코": ⚠ color=green → 원본은 black
  블록 4 "여러분, 감사합니다!": OK
  → 1건 불일치, style 수정 후 재생성 필요
