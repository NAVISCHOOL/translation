C

JSON 메타데이터

서식을 구조화된 JSON으로 기록 (파이프라인 파싱 쉬움)

## page 5
original: この本では...
translated: 이 책에서는...
style: {"size": 14, "color": "#000"}

original: 「ふわふわ」と言った人には...
translated: "후아후아"라고 말한 사람에게는...
style: {"size": 14, "color": "#000"}

original: ✿
translated: ✿
style: {"size": 20, "color": "#228B22", "type": "symbol"}

공통 서식 속성:

  • size — 텍스트 크기 (상대값: small/medium/large 또는 pt 숫자)
  • color — 텍스트 색상 (black, green, red, gray 등)
  • type — 특수 유형 (symbol, title, caption, footnote 등)
  • align — 정렬 (center, right 등, 기본은 left)
  • bold — 굵게 여부
