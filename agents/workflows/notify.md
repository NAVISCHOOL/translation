# 🔔 작업 완료 알람

긴 작업이 완료되면 **항상** 비프음을 울려 사용자에게 알립니다.

## 알람 대상 작업

아래 작업이 완료되면 자동으로 비프음을 울립니다:

- 번역 파이프라인 빌드 (`translate_pipeline.py build`)
- 패키지 설치 (`pip install`, `npm install` 등)
- Git clone / push
- PDF 생성
- 기타 10초 이상 소요되는 작업

## 알람 실행 방법

// turbo
```powershell
[console]::beep(1000, 500); [console]::beep(1200, 500); [console]::beep(1500, 700)
```

## 규칙

- 짧은 파일 읽기/쓰기, 검색 등 즉시 완료되는 작업에는 울리지 않음
- 연속으로 여러 작업을 할 때는 **마지막 작업 완료 시에만** 울림
- 에러로 실패한 경우에도 알람을 울려서 사용자에게 알림
